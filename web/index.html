Model Selection Criteria FDMS Hypothesis Validation
1. Neutral Minority Recovery (fit_prior=False)

TripAdvisor is 73.7% positive. Empirical prior in Model 1 starved the 10.7% neutral class entirely (predicting 0 neutral reviews). Uniform prior gives each class equal base weight, reviving minority class detection.

2. Reduced Laplace Smoothing (α=0.1)

Standard Laplace (α=1.0) over-smoothes word likelihoods across 20,000 TF-IDF features. Reducing alpha to 0.1 sharpens posterior discrimination for hospitality vocabulary (amenities, cleanliness, service).

3. Macro F1 as Primary Criterion

Although Model 2 achieved higher raw accuracy (85.17%), it only detected 64 neutral reviews (F1=0.1477). Model 3 maximizes unweighted Macro F1 (0.6762), ensuring balanced multi-class performance.

Protocol Progress & Adjudication Rules Dual-Reviewer Standard
1. Double-Blind Isolation

Annotators label all 399 reviews without knowledge of each other's decisions or the Naive Bayes model predictions, preventing confirmation bias.

2. Automated Conflict Resolution Engine

ReviewMind provides src/compute_annotation_consensus.py to automatically compare files, identify discordant reviews, and compute Cohen's Kappa.

3. Scientific Integrity Protocol

Under ReviewMind scientific protocol, supervised metrics (Accuracy, F1) are never computed or presented on unverified test data. Metrics will be generated once ground truth is finalized.
